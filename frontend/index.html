Range Partitioning — The employees and salary_history tables are partitioned by hire_date / effective_date using PostgreSQL's declarative partitioning. Each yearly partition enables partition pruning, dramatically reducing I/O for date-range queries. This pattern is identical to Oracle's PARTITION BY RANGE.
